## ✨ Fonctionnalités clés

* 📸 **Partage Social** : Publiez vos recettes avec photos et étapes détaillées.
* 🔥 **Feed Interactif** : Découvrez les tendances et les recettes des personnes que vous suivez.
* ✅ **"J'ai essayé"** : Validez une recette en postant la photo de votre propre résultat.
* 🔍 **Recherche Avancée** : Filtrez par ingrédients, difficulté ou temps de cuisson.

## 🛠️ Stack Technique

* **Frontend** : React.js / Next.js, Tailwind CSS
* **Backend** : Node.js, Express
* **Base de données** : PostgreSQL / MySQL (Sequelize/Prisma)
